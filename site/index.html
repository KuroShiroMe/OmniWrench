OmniWrench

Das Universalwerkzeug für Administratoren.

Alle Admin-Werkzeuge in einem Fenster: Tools wie aus einem App-Store installieren, Zugangsdaten sicher im eingebauten Tresor ablegen und beliebig viele Tools nebeneinander oder in eigenen Fenstern anordnen, mit KI-Assistenten an der Seite. Für Windows 10/11 und Linux.

Herunterladen Quellcode auf GitHub

Version 0.8.1 · Open Source (MIT) · kostenlos

Was OmniWrench kann

Tool-Store

Jedes Tool stellt sich mit Screenshots seiner Funktionen vor und wird mit einem Klick aus GitHub-Repositories installiert und aktualisiert, samt Voraussetzungen wie RSAT, PowerShell-Module oder Python-Pakete. Eigene Repositories lassen sich ergänzen.

Tresor für Zugangsdaten

Passwörter liegen verschlüsselt im Tresor (Argon2id und AES-256-GCM), entsperrt per Masterpasswort oder Smartcard. Tools holen sich Zugangsdaten nur bei Bedarf und nur für die Sitzung.

KI-Assistenten

Über 100 Anbieter von ChatGPT, Claude, Gemini und Copilot bis zu lokalen Modellen oder dem eigenen Firmen-Bot, Modellwahl direkt im Chat. Sie beantworten Fragen zu OmniWrench und zu den Daten der Tools – nur so weit freigegeben (fünf Stufen, je Tool und je Server), mit verfremdeten Adressen und Namen und mit Bestätigung vor jeder Änderung. Chats bleiben lokal und verschlüsselt.

Zehn KI-Tools

Eigene Tools im Bereich „KI-Tools“: Clank (Chat mit Ordnern und Repositories), Pixelizer (Bilder), Groovitron (Musik), Vidcomic (Video), Q-Force (Gruppenchat), Infobot (Dokumente), Orvus (Zeitpläne), Kreeli (Live-Transkription mit Sprechererkennung), Mr. Zurkon (Sprachassistent mit Weckwort, Wetter- und Nachrichtenanzeige) und Gadgetron (MCP). Auf Wunsch komplett offline und kostenlos: Ollama lässt sich direkt aus OmniWrench installieren und mit Modellen bestücken, Whisper, Piper und Vosk richten die Tools bei der Installation selbst ein.

MCP für andere KI-Programme

OmniWrench spricht das Model Context Protocol: fremde MCP-Server lassen sich anbinden, und Claude Desktop, VS Code und andere KI-Programme nutzen die Funktionen von OmniWrench – lokal, mit Token und mit Bestätigung im Programm.

Tabs nach Wunsch

Jedes Tool öffnet sich in einem eigenen Tab. Tabs lassen sich nebeneinander, übereinander oder als eigenes Fenster anordnen, das Layout bleibt beim nächsten Start erhalten.

Ordnung nach Service-Bereichen

Tools sind nach den Bereichen einer IT-Abteilung sortiert, von Netzwerk über Identität bis Service Desk, und über anklickbare Tags schnell zu finden. Die Startseite zeigt sie als Karten mit Screenshots, große oder kleine Symbole oder als Liste.

Updates automatisch

OmniWrench meldet neue Versionen von Programm und Tools und aktualisiert auf Wunsch im Hintergrund. Einstellungen und Tresor bleiben dabei erhalten.

23 Sprachen

Deutsch, Englisch, Französisch, Spanisch und viele weitere, dazu Dialekte von Bayrisch bis Kölsch. Jedes Tool kann eine eigene Sprache verwenden.

Einblicke

Download

Python muss nicht installiert sein, alles Nötige ist enthalten. Aktuelle Version: 0.8.1

Windows 10/11

Installationsprogramm Portable Version (ZIP)

Stille Installation: /VERYSILENT /SUPPRESSMSGBOXES /NORESTART. Die Dateien sind noch nicht signiert, SmartScreen kann beim ersten Start warnen.

Linux (x86_64)

Paket für Debian/Ubuntu (.deb) Portable Version (tar.gz)

Installation: sudo apt install ./omniwrench_*_amd64.deb. Benötigt glibc 2.35 oder neuer.
